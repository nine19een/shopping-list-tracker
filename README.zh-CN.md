# Shopping List Tracker

一个记录家庭采购的小型 Tkinter 桌面工具，界面为中文。添加物品及价格后，可拖动条目，在“待选”“未购买”“已购买”三列间移动。每列显示件数、金额，以及实时的勾选统计。

## 运行

使用 Python 3.11+，并确保已安装 Tkinter、能够打开图形桌面窗口。在仓库目录运行：

```bash
python list.py
```

程序只使用 Python 标准库，无需账号或预先准备数据文件。

## 使用与数据

1. 填写非空物品名称和非负、有限的数字价格，价格单位标为“元”，然后点击“添加到清单”。新条目会进入“待选”。
2. 将条目行拖入另一列即可改变状态。复选框用于勾选统计及“删除勾选”，勾选本身不会改变状态。

“总预算”计算全部条目的金额，包括已购买条目。金额显示两位小数，保存的价格则保留输入的小数精度。

添加、移动或删除条目时，程序会将数据保存到用户主目录的 `shopping_tracker_data.json`，启动时重新读取。勾选状态不会保存。

保存失败没有提示，无效 JSON 会被忽略，结构异常的数据记录可能导致加载中断。请自行备份；程序没有撤销功能。请使用有限数值：`NaN` 可能抛出异常，`Infinity` 目前会被接受。

## 可选可执行文件

打包需要另行安装 PyInstaller：

```bash
python -m PyInstaller --noconsole --onefile --name "统计清单" list.py
```

原有说明中的 Windows 输出为 `dist/统计清单.exe`，本次未验证打包。打包后的程序仍使用同一主目录数据文件。请勿将生成的数据、`dist/`、`build/` 或 `__pycache__/` 纳入版本控制。
